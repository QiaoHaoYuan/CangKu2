# 课表 Mini App（空白模板）

一周课表，谁用谁自己填。这个版本**没有预置任何课程**，打开就是空的。

## 功能

- 点空白格子 → 添加课程（课程名、教室、老师、备注、颜色）
- 点已有的课程块 → 编辑或删除
- 设置里可以：显示/隐藏周末、调整每天节数
- 今天那一列自动高亮
- 数据只保存在本机，不上传任何地方

## 怎么用

1. 把 `timetable` 整个文件夹放到 Fish Pocket 的 `~/apps/` 目录下
2. 打开 Fish Pocket → Mini Apps → 课表
3. 点空格开始填自己的课

每个人在自己的手机上各填各的，互不影响。

## 想改

- **作息时间**：`App.jsx` 顶部的 `PERIOD_TIMES` 是每节课的起止时间，按你们学校的铃声改
- **想预置课程**：往 `SEED` 数组里加对象就行（模板默认是空数组）
- **配色**：`COLORS` 数组，或者 `style.css` 里的 CSS 变量

## 文件

| 文件 | 作用 |
| --- | --- |
| `App.jsx` | 主界面与逻辑 |
| `style.css` | 样式 |
| `i18n.js` | 中/英/日文案 |
| `app.json` | Mini App 的名称、图标、配色 |

> 需要 Fish Pocket 才能作为 Mini App 运行。想让人在浏览器里直接打开，可以再出一个单文件 HTML 版本。
